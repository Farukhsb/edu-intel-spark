# GradeAI User Guide

## Introduction

GradeAI is an academic workflow platform designed to help educators manage assessment, monitor student performance, identify academic risk early, and support students before problems become more serious.

The platform brings together:

- assignment creation
- rubric-based marking
- student submissions
- AI-assisted grading
- lecturer review and final decision-making
- academic integrity checks
- moderation workflows
- student feedback release
- guided student improvement support
- analytics and early intervention insight

GradeAI does not replace lecturer judgement. AI is used to support marking, explanation, and pattern detection, but lecturers remain responsible for reviewing work, approving grades, and deciding what is released to students.

## Who GradeAI Is For

GradeAI supports different types of users:

- **Lecturers / Teachers**
  - create assignments
  - define rubrics
  - import existing grades from CSV or image on the lecturer overview page
  - review submissions
  - use AI-assisted marking
  - approve and release grades
  - monitor performance patterns
  - identify students who may need support

- **Students**
  - view published assignments
  - submit work
  - view released grades and feedback
  - use `Explain My Grade` to better understand performance and improve

- **Moderators**
  - review moderation cases
  - confirm, adjust, return, or escalate review outcomes

- **Admins**
  - monitor platform activity
  - oversee users, assignments, submissions, and system-level trends

## Getting Started

Sign in and GradeAI takes you to the right workspace for your role:

- lecturers see the lecturer dashboard
- students see student pages
- admins see the admin dashboard

If you are a lecturer, the main things you will use are:

- `Overview` for workload and risk signals
- `Assignments` for briefs, rubrics, submissions, and grading
- `Academic Integrity` for similarity and review cases
- `Moderation` for second-pass review
- `Cohort Analytics` and `Performance Trends` for patterns over time
- `Import Grades` on the lecturer overview when you already have marks in CSV or image form

## Lecturer Workflow

1. Create the assignment.
2. Add a clear brief and rubric.
3. Publish it for students.
4. Review submissions, run AI-assisted grading, and check integrity or moderation where needed.
5. Approve and release the result.

Imported grades follow the same pattern. You can map them to an existing assignment or create a new imported assignment first. Once confirmed, they feed into the same analytics pages as the rest of the data.

## Student Workflow

Students can:

- view published assignments
- submit work
- see released grades and feedback
- use `Explain My Grade` to understand what to improve

## Moderator And Admin

Moderators review cases that need another academic judgement. Admins use the platform for oversight, reporting, and user management. Reporting pages like `Institutional Insights`, `Accreditation`, and `External Examiner` live in the admin area.

## Good Defaults

- write short, clear briefs
- keep rubrics specific
- treat AI output as draft support
- release only after review
- use analytics and integrity signals as prompts, not conclusions
