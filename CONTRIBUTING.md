# Contributing to edu-intel-spark

Thank you for your interest in contributing to the edu-intel-spark project! Here are some guidelines to help you get started:

## How to Contribute
1. **Fork the repository**: Click the fork button on the top right of the repository page.
2. **Clone your fork**:  `git clone https://github.com/your-username/edu-intel-spark.git`
3. **Create a branch**: `git checkout -b feature/your-feature-name`
4. **Make your changes**: Work on your feature or bug fix.
5. **Commit your changes**: `git commit -m "Describe your changes here"`
6. **Push to your fork**: `git push origin feature/your-feature-name`
7. **Create a Pull Request**: Visit the original repository and click on "New Pull Request".

## Pull Request Guidelines
- Clearly describe the purpose of the pull request.
- Include screenshots for visual changes (if applicable).
- Reference any relevant issues or discussion.

## Code of Conduct
Please be respectful to everyone in the community. Any form of discrimination, harassment, or unprofessional behavior will not be tolerated.

## License
By contributing, you agree that your contributions will be licensed under the project's license.

Happy contributing!
